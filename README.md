# Antiguidade Europeia — Curso Interativo

Aplicativo estático em HTML, CSS e JavaScript, pensado para publicação direta no GitHub Pages.

## Recursos
- 12 módulos e 36 aulas.
- Progresso salvo no navegador (localStorage).
- Atividades interativas variadas: múltipla escolha, verdadeiro/falso, associação, ordenação, classificação, análise de fonte e identificação por pistas.
- Linha do tempo, glossário e pesquisa global.
- Layout responsivo, modo claro/escuro, foco visível e navegação por teclado.
- PWA básica e cache offline via Service Worker.

## Publicação no GitHub Pages
Envie todos os arquivos para a raiz do repositório e ative **Settings → Pages → Deploy from a branch**.

## Observação
O conteúdo didático procura distinguir evidência, hipótese e convenções historiográficas. Datas antigas são aproximadas quando a documentação não permite precisão absoluta.
